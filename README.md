# Tic Tac Toe

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

* Two-player gameplay (X and O)
* Winner detection
* Draw detection
* Reset Game button
* New Game button
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Start playing!
